# Hi, I’m Kumori

I build accessible, human-approved creative technology for artists, craftspeople, musicians, independent shops, and people without expensive hardware or large AI budgets.

My work centers on making AI-assisted creation easier to understand, safer to approve, and more practical for everyday creators.

## Current flagship

### Solforge

Solforge is a creator-first platform that turns a simple idea into a structured plan, safe preview, and verifiable signed artifact.

The working model currently uses Qwen through an OpenAI-compatible API. The roadmap expands that foundation toward additional hosted and local model providers as funding, API access, and contributor capacity grow.

- [Open the working model](https://solforge.nanokat.com)
- [View the public competition project](https://github.com/nanokataclysm/nanokat-forge)

## Current focus

- preparing Solforge for a clean public-alpha release;
- expanding its provider architecture without locking creators to one model vendor;
- improving human approval, artifact verification, and creator-focused usability;
- keeping sensitive operations, secrets, and personal data outside public workflows.

## Principles

- Human approval before consequential actions
- Secure and recoverable systems
- Honest claims about what is shipped
- Accessible tools for people with limited hardware or API budgets
- Small, reviewable, reversible changes
